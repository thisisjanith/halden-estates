# Halden Estates

Boutique real estate website with a scroll-driven 3D villa hero (day to dusk), filterable listings with a map, featured-home walkthrough, neighbourhood guide and mortgage calculator.

**Live:** https://halden-estates.netlify.app

## Tech
Vite · vanilla JavaScript · GSAP (ScrollTrigger) · Lenis smooth scroll · Three.js

## Run locally
```bash
npm install
npm run dev
```

Build with `npm run build` (output in `dist/`).
